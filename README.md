# FPV Voxel — Drone Flight Simulator

An FPV drone flying game with procedurally generated Minecraft-style voxel worlds. Built with Godot 4, runs on Android/iOS. Supports FPV controllers via Bluetooth, USB, or a custom ESP32-C6 BLE bridge.

See [GAME_PLAN.md](GAME_PLAN.md) for the full development plan.
